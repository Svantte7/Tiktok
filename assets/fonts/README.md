# Kirjasimet

Kaikki kirjasimet ovat SIL Open Font License 1.1 -lisenssin alaisia ja
isännöidään tältä palvelimelta. Sivusto ei tee yhtään ulkoista pyyntöä.

| Tiedosto | Kirjasin | Käyttö |
|---|---|---|
| `barlowcondensed-700.woff2` | Barlow Condensed Bold | Otsikot, hinnat, tunnusluvut |
| `barlow-500.woff2` | Barlow Medium | Käyttöliittymä, navigaatio |
| `barlow-600.woff2` | Barlow SemiBold | Painikkeet, etiketit |
| `sourceserif4-400.woff2` | Source Serif 4 Regular | Leipäteksti |
| `sourceserif4-600.woff2` | Source Serif 4 SemiBold | Korostukset leipätekstissä |

Barlow: © Jeremy Tribby. Source Serif 4: © Adobe.
Lisenssit: `OFL-Barlow.txt`, `OFL-SourceSerif4.txt`.

Tiedostot on karsittu latinalaiseen merkistöön (sis. Latin Extended-A, joten
suomi, ruotsi, viro ja baltiankielet toimivat) sekä käytettyihin
typografisiin merkkeihin. Source Serif 4 on instansoitu muuttujafontista
optiseen kokoon 14.
